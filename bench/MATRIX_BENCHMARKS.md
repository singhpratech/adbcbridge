# Per-database benchmarks

Generated by `bench/matrix_bench.py` on 2026-08-23. Servers run locally in Docker, so numbers are dominated by the ODBC driver + database, not the network.

Bulk ingest binds each Arrow batch as an ODBC parameter array and commits the whole
stream once (see `bench/BENCHMARKS.md`, which has the before/after numbers for both
halves). Three drivers opt out of parameter arrays because theirs silently drop
values -- DuckDB, clickhouse-odbc and Firebird's OdbcFb -- and fall back to one
execute per row inside the same single transaction.

clickhouse-odbc is the outlier: it speaks HTTP, so every row is its own request, and
it reports no transaction support to batch them with. The MergeTree table in this
benchmark also turns each of those requests into its own part, which ClickHouse then
throttles. Treat its ingest number as the driver's request-per-row floor, not as a
property of adbcbridge.
